## The flow

Pre-register in four steps without an account, turn it into an account in four more, then log in. Twelve screens: home, your details, plan choice (Standard or Gaïa), summary, confirmation, account creation, plan, account summary, email check, login, forgotten password, member space.

## How it's built

- **One codebase.** Expo builds iOS, Android and web from the same code. Tested on a phone with Expo Go, demoed in the browser.
- **`app/` = screens.** With expo-router every file in `app/` is a screen, so the folder reads like the flow.
- **Forms.** react-hook-form with Zod schemas: one source of truth for validation, like the 12-character password rule.
- **`theme.ts`.** The mockups' colours live in one constants file, so design and code can't drift apart.
