## Le parcours

Se pré-inscrire en quatre étapes sans compte, transformer cette pré-inscription en compte en quatre autres, puis se connecter. Douze écrans : accueil, coordonnées, choix de la formule (Standard ou Gaïa), récapitulatif, confirmation, création du compte, formule, récapitulatif du compte, vérification de l’e-mail, connexion, mot de passe oublié, espace membre.

## Comment c’est construit

- **Une seule base de code.** Expo génère iOS, Android et le web à partir du même code. Testée sur téléphone avec Expo Go, présentée dans le navigateur.
- **`app/` = les écrans.** Avec expo-router, chaque fichier de `app/` est un écran : le dossier se lit comme le parcours.
- **Formulaires.** react-hook-form avec des schémas Zod : une seule source de vérité pour la validation, comme la règle du mot de passe de 12 caractères.
- **`theme.ts`.** Les couleurs des maquettes sont dans un seul fichier de constantes, pour que le design et le code ne divergent pas.
